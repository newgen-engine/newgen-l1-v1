# Evidence publication scope

The package contains selected historical private-testnet results:

- Exact original A/B/C API captures from 8 October 2026 at H328270.
- Selected complete fields and verbatim field fragments from the 16 November
  restart transcript, including initial A H328556 and later A/B/C H328559.
- Three preserved historical summaries for the previously selected results,
  including offline database verification at H328556.

The original October archive, launch scripts, original operational logs,
credentials, databases and full private filesystem layout are excluded.
The selected API files retain public validator identifiers and historical
private-testnet metadata. The November API transcript is truncated; no missing
data has been reconstructed. This publication does not claim to include all
tests, an uninterrupted error-free run, or a complete security certification.

The October and November executable references differ. Their evidence remains
separate. See EVIDENCE_REPORT.md and EVIDENCE_INDEX.json for identity limits.
